# Binary Classification

## Opis projektu
Projekt polegający na budowie modelu klasyfikacji binarnej dla sztucznie wygenerowanego zbioru danych. Obejmuje przygotowanie danych, eksploracyjną analizę danych (EDA), implementację modeli, ich ocenę oraz interpretację wyników w Pythonie.

## Zakres projektu
- przygotowanie i wstępna analiza danych,
- eksploracyjna analiza danych (EDA),
- budowa modeli klasyfikacji binarnej,
- ocena jakości modeli,
- interpretacja otrzymanych wyników.

## Zawartość repozytorium
- `Projekt_klasyfikacja_binarna.ipynb` – notebook z implementacją projektu,
- `Klasyfikacja_binarna_raport.pdf` – raport opisujący założenia, przebieg analizy i wyniki.

## Wykorzystane narzędzia
- **Python**
- **NumPy**
- **Pandas**
- **scikit-learn**
- **Jupyter Notebook**
